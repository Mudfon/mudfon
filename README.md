# MUDFON Website

Official website for the **Muslim Ummah Development Forum of Nigeria (MUDFON)**.

## Motto

**Building the Ummah, Transforming Lives**

## Official Slogan

**One Ummah • One Vision • One Future**

## Vision

To build a united, knowledgeable and empowered Ummah.

## About

MUDFON is a platform dedicated to promoting unity, knowledge, leadership and community development among Muslims in Nigeria.

## Website Features

- Responsive modern design
- Mobile-friendly navigation
- About MUDFON section
- Focus areas
- Community development programs
- Join Us section
- Contact section
- Responsive layout for phones, tablets and computers

## Project Files

- `index.html` — Website structure and content
- `style.css` — Website design and responsive styling
- `script.js` — Mobile navigation and dynamic copyright year
- `README.md` — Project documentation

## Technologies

- HTML5
- CSS3
- JavaScript

## Deployment

This is a static website and can be deployed using **GitHub Pages**.
